### 최종 선택

- 사용자가 직접 선택한 파일: **프로야구기록_B_v1.html**.
- 선택하지 않은 파일: 프로야구기록_A_v1.html. 위 비교표의 설명으로 결과를 남기며, 최종 제출 HTML에서는 제외한다.
- 본인이 작성한 선택 근거 1~3줄: **[작성 필요: 직접 사용하며 A와 비교해 B를 선택한 이유를 본인 표현으로 작성한다.]**

선택 근거 질문에서 작성 의사는 표시했으나 실제 이유 문장은 입력되지 않았다. 따라서 AI가 선택 이유를 대신 작성하지 않았다.

## 4. 선택한 HTML의 사용자 테스트 3건

사용자는 두 HTML의 비교와 선택한 파일의 테스트 3건(조건 변경 포함)을 모두 직접 확인했다고 답했다. 다만 세부 결과는 미작성으로 선택했으므로, 구체적인 행동·예상 결과·실제 결과는 아직 기록되지 않았다.

아래의 행동과 예상 결과는 **작성용 예시**다. 실제 수행한 테스트에 맞게 바꾸고, 직접 관찰한 실제 결과를 입력해야 한다. 이 표를 현재 상태 그대로 완료된 사용자 테스트 기록으로 간주하지 않는다.

- 테스트 대상: 프로야구기록_B_v1.html
- 사용 브라우저 / 기기: **[작성 필요]**
- 테스트 날짜: **[작성 필요]**

| 번호 | 테스트 내용 — 실제 수행한 행동 | 예상 결과 | 실제 결과 — 본인이 관찰한 내용 |
|---|---|---|---|
| 1 | [예시] 파일을 열고 기본 선택 연도를 확인한 뒤 1982년, 1999년을 차례로 선택한다. | 처음에는 2026년이 선택된다. 1982년은 전기·후기 표, 1999년은 드림·매직리그 표가 나오고 한국시리즈 제목·내용·출처·상태도 선택 연도에 맞게 바뀐다. | **[미작성: 실제 행동과 결과를 기록]** |
| 2 | [예시] 1985년을 선택하고 한국시리즈 영역을 확인한다. | 삼성의 전·후기 통합우승에 따른 한국시리즈 미개최 안내가 표시되고, 가상의 준우승 팀이나 경기 결과가 표시되지 않는다. | **[미작성: 실제 행동과 결과를 기록]** |
| 3 | [조건 변경 예시] 브라우저 화면 폭을 360px로 바꾸고 2023년을 선택한 뒤 정규리그 표와 한국시리즈 표를 가로로 스크롤한다. | 연도 선택과 모든 구역에 접근할 수 있고, 넓은 표의 마지막 열까지 표 안에서 스크롤해 확인할 수 있다. 페이지 오른쪽 내용이 접근 불가능하게 잘리지 않는다. | **[미작성: 실제 화면 폭·조작·결과를 기록]** |

예상과 다른 결과가 나왔다면 실패한 결과도 그대로 적는다. 실제로 하지 않은 행동이나 AI 검사 결과를 본인이 수행한 결과로 옮겨 적지 않는다.

## 5. AI 보조 검사 기록

이 절은 사용자 테스트를 보충하는 참고 기록이며, 4절의 직접 테스트 3건을 대신하지 않는다.

- 실행 환경: Windows의 Chrome, 자동 브라우저 검사.
- 공통 조건: 같은 컴퓨터에서 A·B를 각각 `file://` 방식으로 열고, 오프라인 상태에서 검사.
- 화면 폭: 기본 1440px, 변경 조건 360px.

| 검사 내용 | 예상 결과 | 실제 결과 |
|---|---|---|
| A·B에서 기본 연도와 선택 항목을 확인하고 1982~2026년을 모두 전환 | 기본값은 2026년이며 45개 연도가 있고, 선택 연도가 정규리그 영역 제목에 반영됨 | 두 파일 모두 해당 조건 확인. 전환 중 JavaScript 오류 없음. 모든 연도의 데이터 정확성을 확인한 것은 아님 |
| A·B에서 1985년을 선택 | 한국시리즈 미개최 안내가 나오고 가상의 경기 표가 없음 | 두 파일 모두 미개최 안내 확인. 한국시리즈 경기 결과 행 없음 |
| A·B를 360px로 바꾸고 연도를 전환한 뒤 2023년 표를 끝까지 가로 스크롤 | 페이지 자체가 가로로 넘치지 않고 표의 마지막 열에 접근 가능 | 45개 연도에서 페이지 가로 넘침 없음. 2023년 정규리그·한국시리즈 표의 마지막 열 접근 확인 |
| A·B를 오프라인으로 열어 내장 기록 조회 | 외부 파일·API·서버 없이 화면과 연도 조회가 동작 | 두 파일 모두 동작. HTTP·HTTPS 리소스 요청 없음 |
