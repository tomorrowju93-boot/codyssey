# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT 6.1 Sol / chatgpt_screenshot_01.png, chatgpt_screenshot_02.png
- 더한 기능과 고른 이유:
  - 영화 제목 수정: 잘못 입력한 제목을 영화를 삭제하고 다시 추가하지 않고 고치기 위해 요청함.
  - 영화 삭제: 필요 없는 영화를 목록에서 제거하기 위해 요청함.
  - 카드 안에서 등급 선택: 영화 카드를 누르면 그 카드 안에 등급 선택 상자가 나타나고, S·A·B·C·미분류 중 하나를 고르면 바로 이동하도록 요청함.
  - 카드의 드래그 안내: 카드 제목 영역에 ‘끌어서 이동’ 안내를 표시해 이동 방법을 쉽게 알아볼 수 있도록 요청함.
  - UI 조건: 별도의 레이어나 공통 관리 영역 대신 해당 카드 안에서 제목 수정·삭제·등급 변경을 처리하도록 정함. 기존 영화 추가, 카드 선택 후 등급 글자 누르기, 드래그 이동, 저장, 초기화 등의 기능은 유지하도록 요청함.
  - 요청한 기능과 성공 조건은 ‘기획서.md’의 기존 완성 기준 끝에 덧붙였음.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| 첫 번째 HTML 전체 코드 — 저장 시 제안 이름: 영화_기능추가.html | 제목 수정·삭제·등급 변경을 카드 밖의 공통 관리 영역에서 처리하도록 제시됨. 사용자가 원하는 ‘각 영화 카드 안에서 조작하기’ 조건과 달랐음. 기존 기능이 망가졌는지는 브라우저에서 확인한 결과가 아직 없음. | 고치기: 각 카드 안에서 조작하도록 UI 변경을 요청하고, 카드에 드래그 이동 안내도 추가하도록 요청함. |

- 원본의 기존 완성 기준을 직접 확인한 결과 모두 정상 작동됨
- 실제 저장한 HTML 파일명과 각 버전의 테스트 결과 제목 수정,삭제,등급 변경 등 기능상 이유는 아니지만 UI 수정이 필요해서 추가 요청하고 테스트 한 결과 정상 작동함
- 제목 수정·취소·빈 제목 및 중복 제목 처리, 삭제 확인·취소, 등급 선택 상자의 즉시 이동, 드래그 안내 확인 결과 모두 정상 작동함
- 새 기능 사용 후에도 기존 추가·이동·저장·좁은 화면 표시·초기화 기능이 유지되는지 확인한 결과 정상 작동함
- 모든 영화를 삭제한 뒤 다시 열어도 빈 목록이 유지되는지 확인한 결과 정상 작동함
- 최종 완성본은 영화_기능추가_수정1.html 임. 원본 파일을 직접 수정하지 않았음.
- 주요 대화 캡처 파일명 : chatgpt_screenshot_01.png, chatgpt_screenshot_02.png

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 같은 기능이라도 공통 관리 영역과 카드 내부 조작 방식은 사용 흐름이 다르므로, 원하는 UI 위치를 AI에게 어떻게 구체적으로 전달했는지 비교하고 싶음. 또한 새 기능이 동작하는지뿐 아니라 기존 기능도 함께 확인하고, 기존 기능이 망가졌을 때 원본으로 돌아가는 기준을 이야기하고 싶음.
