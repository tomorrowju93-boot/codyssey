# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.

### 추가 기능의 완성 기준

- 영화 제목 수정: 각 영화 카드의 ‘수정’을 누르면 해당 카드 안에 제목 입력란과 ‘저장’·‘취소’ 버튼이 나타납니다. 제목을 바꾸고 ‘저장’을 누르면 해당 카드의 제목만 바뀌고, 영화 개수와 기존 등급은 유지됩니다.
- 제목 수정 취소·입력 확인: 제목을 바꾸다가 ‘취소’를 누르면 원래 제목을 유지합니다. 수정할 제목이 비어 있거나 공백뿐이면 저장하지 않고 안내를 보여 줍니다. 다른 영화와 같은 제목으로 수정하려 하면 중복 안내를 보여 주고 기존 제목을 유지합니다.
- 영화 삭제: 각 영화 카드의 ‘삭제’를 누르면 삭제 여부를 확인합니다. 확인하면 해당 영화 카드만 목록에서 사라지고 다른 영화의 제목과 등급은 유지됩니다. 취소하면 카드가 그대로 남습니다.
- 카드 안에서 등급 변경: 영화 카드의 제목 영역을 누르면 해당 카드 안에 S·A·B·C·미분류를 고를 수 있는 선택 상자가 나타나고 현재 등급이 선택되어 있습니다. 다른 등급을 고르면 추가 적용 버튼 없이 해당 칸으로 즉시 이동하며, 영화가 중복으로 생기지 않습니다.
- 드래그 안내: 각 카드의 제목 영역에 ‘끌어서 이동’ 안내가 보입니다. 안내가 있는 제목 영역을 끌어 다른 등급 칸이나 미분류에 놓으면 해당 영화가 이동합니다.
- 카드 내부 조작: 제목 수정 입력란, 저장·취소·삭제 버튼과 등급 선택 상자는 모두 해당 카드 안에 표시됩니다. 이 조작을 할 때 의도하지 않은 카드 이동이 발생하지 않습니다.
- 변경 내용 저장: 제목을 수정하고 영화를 삭제하거나 등급을 변경한 뒤 같은 브라우저에서 같은 파일을 다시 열면 수정한 제목, 삭제 결과, 등급 배치가 유지됩니다. 모든 영화를 삭제한 경우에도 빈 목록이 유지됩니다.
- 초기화와 기존 기능 유지: 제목 수정·삭제·등급 변경 후 ‘처음으로’를 누르면 기본 영화 8개가 원래 제목으로 모두 미분류에 돌아오고 직접 추가한 영화는 사라집니다. 기존의 영화 추가, 카드 선택 후 등급 글자 누르기, 드래그 이동, 자동 저장, 좁은 화면 표시, HTML 한 장 실행과 빈 제목 추가 방지도 계속 동작합니다.
