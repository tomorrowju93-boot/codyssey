# 미션 3 기록

직접 사용한 결과를 바탕으로 민수의 기획서와 받은 피드백을 비교함. 아래의 직접 확인 결과는 사용자가 브라우저에서 시험하여 전달한 내용이며, AI가 별도로 화면을 조작한 결과는 아님. 장점에 대한 ‘반영’은 해당 동작과 구성을 유지한다는 의미임.

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI: 저장 기능이 없다. | 영화를 분류하고 새 영화를 추가한 뒤 파일을 닫았다가 같은 브라우저에서 다시 열자, 기존 분류가 남지 않고 모두 미분류로 초기화됨. | 반영 | 기획서의 ‘같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다’를 충족하지 못함. 영화 목록과 등급을 저장하고 다시 불러오도록 개선할 필요가 있음. |
| AI: ‘처음으로’가 직접 추가한 영화를 지우지 않는다. | 새 영화를 추가한 뒤 ‘처음으로’를 누르자 추가한 영화가 정상적으로 사라짐. 기본 영화 8개도 미분류로 돌아감. | 보류 | 직접 확인한 결과와 AI의 주장이 다름. 기획서대로 동작하므로 이 의견에 따른 수정은 필요하지 않음. |
| AI: 빈 제목을 막지 않아 기획서를 어긴다. | 빈 입력과 공백만 입력한 경우에도 새 영화 카드가 생성됨. 기획서에는 빈 제목을 금지한 조건이 없음. | 반영 | 빈 카드 방지는 사용성 개선으로 반영함. 다만 ‘기획서 위반’이라는 설명은 채택하지 않음. 제목을 식별할 수 없는 카드가 생기는 불편을 줄이기 위해 입력 안내가 필요함. |
| AI: 이 세 가지 외에는 완성 기준을 잘 지킨다. | 화면 폭을 좁히면 오른쪽 영역이 잘려 내용을 볼 수 없음. 재실행 시 분류도 초기화됨. | 보류 | 저장 문제는 AI도 이미 지적했지만, 화면 잘림은 별도로 놓친 문제임. 따라서 나머지 완성 기준을 모두 충족한다는 포괄적 판단은 받아들이지 않음. |
| 동료: 등급마다 색이 달라 알아보기 쉽다. | S·A·B·C가 색으로 구분되어 등급을 알아보기 쉬웠음. | 반영 | 영화 취향을 등급으로 정리하는 목적에 도움이 되므로 현재 구분을 유지함. |
| 동료: 분류한 영화 수가 표시되어 진행 상황을 알 수 있다. | 영화를 옮겼다가 미분류로 되돌렸을 때 표시 숫자도 맞게 바뀌는 것을 확인함. | 반영 | 분류 진행 상황을 파악하는 데 도움이 되므로 유지함. |
| 동료: 드래그할 때 칸 색이 바뀌어 놓을 위치를 알 수 있다. | 카드를 누른 채 등급 칸 위로 가져가자 칸 색이 바뀌는 것을 확인함. | 반영 | 카드를 놓을 위치를 알려 주는 유용한 표시이므로 유지함. |
| 동료: 휴대폰에서 불편하다. | 모바일에서 화면 내용이 잘려 전체 내용을 볼 수 없음을 확인함. | 반영 | 좁은 화면에서도 오른쪽이 잘리지 않아야 한다는 완성 기준과 연결됨. 화면 폭에 맞춰 배치가 조정되도록 개선해야 함. |
| 동료: 카드 옮기는 게 처음에는 헷갈린다. | 기본 영화 8개는 두 이동 방식 모두 정상 동작했음. 사용자는 PC에서는 불편하지 않았고 모바일에서는 화면 잘림과 작은 화면 때문에 불편했다고 설명함. 최초 사용 시 무엇이 헷갈렸는지는 특정되지 않음. | 되묻기 | 질문: ‘처음 사용할 때 카드 선택 방법, 등급 글자 누르기, 드래그 위치 중 어느 부분이 헷갈렸나요? 사용한 기기와 당시 행동도 알려 주세요.’ 모바일 화면 잘림은 별도 항목으로 반영함. |
| 동료: 아래의 미분류 카드를 S칸으로 끌어 올릴 때 스크롤이 필요해 불편하다. | 해당 스크롤 동작에 대한 별도의 직접 확인 결과는 아직 없음. | 보류 | 의견의 뜻은 이해되지만 재현 확인이 남아 있어 배치 변경을 결정하지 않음. 영화 수와 화면 높이를 바꿔 직접 확인한 뒤 재검토함. |
| 동료: 카드 색이 칙칙하다. | 사용자는 기능상 불편보다는 개인 취향에 관한 의견으로 판단함. | 보류 | 등급 색 구분은 현재도 알아보기 쉬움. 취향만으로 색을 바꿀 필요는 없으며 향후 디자인 검토 때 참고함. |
| 동료: 영화 포스터가 있으면 보기 좋겠다. | 사용자는 개인 취향과 향후 기획 제안으로 판단함. 포스터가 없어 영화 이동이나 분류가 안 되는 문제는 확인하지 않음. | 보류 | 현재 기획서에 없는 추가 기능임. HTML 한 장으로 외부 파일 없이 연다는 조건과 자료 준비 방법을 함께 검토한 뒤 결정할 사항임. |
| 동료: C칸은 없어도 될 것 같다. | 사용자는 기능상 문제보다 개인 취향에 관한 의견으로 판단함. C칸으로 영화 이동은 정상 동작함. | 보류 | 기획서가 S·A·B·C 네 등급으로 취향을 정리하도록 정했으므로 C칸 삭제는 목적과 약속을 바꾸는 제안임. 현재는 유지함. |
| 동료: 큰 문제는 없으므로 PASS를 주겠다. | 저장 유지와 좁은 화면 표시에서 기획서와 다른 동작을 직접 확인함. | 보류 | 동료의 평가 의견은 존중하지만, 확인된 완성 기준 미충족을 해결됐다고 볼 수는 없음. 구체적인 문제와 개선 제안을 전달함. |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 30자 이상의 긴 제목을 추가하면 제목이 카드 밖으로 넘쳐 표시되는 문제를 발견함. 받은 피드백에는 긴 제목 표시 문제를 구체적으로 언급한 내용이 없음.
  - 같은 제목을 다시 입력하면 동일한 제목의 영화 카드가 중복 생성됨. 기획서에 중복 금지 조건은 없으므로 필수 오류 수정이 아닌 사용성 개선 제안으로 전달함.
  - 좁은 화면의 오른쪽 잘림은 받은 피드백을 보기 전에도 직접 발견했음. 동료의 ‘휴대폰에서 불편하다’는 의견과 연결되는 구체적인 증상임.
  - 특수문자 입력 제한이 없다는 점도 관찰했으나, 특수문자로 인한 별도의 문제는 확인하지 않았음. 따라서 특수문자 금지를 개선안에 넣지는 않음.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - AI가 말한 ‘처음으로’ 문제는 직접 시험한 결과와 달랐음. AI의 설명을 그대로 믿지 않고 같은 행동으로 확인하는 방법을 비교하고 싶음.
  - 기획서에 없는 빈 제목·중복 제목 문제를 ‘기획서 위반’과 ‘사용성 개선’으로 어떻게 구분하는지 이야기하고 싶음.
