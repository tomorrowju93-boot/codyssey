# 민수 님께 드리는 피드백

잘된 점: 기본 영화 8개를 모두 옮겨 보니 드래그앤드롭과 ‘카드 선택 → 등급 글자 선택’이 정상 동작했습니다. 영화는 한 칸에만 남았고, 등급별 색과 분류한 영화 수 표시 덕분에 정리 상태를 알아보기 쉬웠습니다. 드래그 중 칸 색이 바뀌어 놓을 위치도 알 수 있었습니다. ‘처음으로’를 누르면 추가한 영화가 사라지고 기본 영화 8개가 미분류로 돌아왔으며, 외부 파일이나 로그인 없이 HTML 한 장으로 열리는 점도 좋았습니다.

고치면 좋을 점

1. 본 것: 영화를 등급 칸에 배치한 뒤 파일을 닫고 같은 브라우저에서 다시 열었더니, 기존 등급 배치가 사라지고 모두 미분류로 돌아갔습니다.
   기준: 기획서의 ‘같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다’라는 조건입니다.
   제안: 추가한 영화 목록과 등급 배치를 브라우저에 자동 저장하고, 다시 열 때 불러오면 좋겠습니다. 수정 후에는 기본 영화와 추가한 영화를 각각 분류한 뒤 파일을 닫았다 열어 목록과 등급이 유지되는지 확인해 주세요.

2. 본 것: 화면 폭을 좁히거나 모바일에서 열었더니 오른쪽 영역이 잘려 전체 내용을 볼 수 없었습니다. 작은 화면에서는 카드를 옮기는 작업도 불편했습니다.
   기준: 기획서의 ‘화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다’라는 조건입니다.
   제안: 화면 폭에 맞춰 등급 칸과 카드가 줄바꿈되거나 배치가 조정되도록 바꾸면 좋겠습니다. 좁은 화면에서도 모든 등급과 미분류 영역에 접근할 수 있고, 카드 선택 후 등급을 눌러 옮길 수 있는지 확인해 주세요.

3. 본 것: 제목을 입력하지 않고 ‘추가’를 누르거나 공백만 입력했더니 글자 없는 영화 카드가 생성됐습니다.
   기준: 기획서에 빈 제목을 금지한 조건은 없지만, 제목이 없는 카드는 어떤 영화인지 알아볼 수 없어 사용하기 불편했습니다.
   제안: 공백만 있는 입력을 포함해 제목이 비어 있으면 카드를 만들지 않고 ‘영화 제목을 입력해 주세요’라고 안내하면 좋겠습니다.

4. 본 것: 30자 이상의 긴 영화 제목을 추가했더니 제목이 카드 크기를 넘어 표시됐습니다.
   기준: 기획서에 제목 길이 제한은 없지만, 제목이 카드 밖으로 넘치면 목록을 읽기 불편합니다.
   제안: 긴 제목도 카드 안에서 줄바꿈되고 필요한 만큼 카드 높이가 늘어나도록 하면 좋겠습니다. 제목 길이를 제한하려면 허용 길이를 정해 입력 전에 안내해 주세요. 특수문자를 금지해야 하는 문제는 확인하지 않았으므로, 이번 제안은 긴 제목의 표시 개선에 한정합니다.

5. 본 것: 이미 있는 영화와 같은 제목을 입력했더니 같은 제목의 카드가 또 생성됐습니다.
   기준: 기획서에 중복 금지 조건은 없지만, 같은 영화를 실수로 여러 번 추가하면 분류 목록을 관리하기 불편할 수 있습니다.
   제안: 사용성 개선으로, 같은 제목이 있으면 ‘이미 추가한 영화입니다’라고 알려 실수로 중복 추가하는 것을 막는 방식을 고려해 주세요. 같은 제목의 다른 작품을 구분해 넣을 필요가 있다면 연도 등을 제목에 함께 적는 방식도 정할 수 있습니다.
