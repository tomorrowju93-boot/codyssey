### 단계별 계산 과정

1. **추가 필요량 계산**:

$$\text{추가 필요량} = \max(0, \text{총소요량} - \text{현재 보유량})$$


$$17\text{개} - 10\text{개} = 7\text{개}$$


2. **구매 팩 수 및 실제 구매량 계산**:
* 판매 규격: 1팩 = 6개
* 필요 수량(7개) 충족을 위한 최소 팩 수:

$$\lceil 7 \div 6 \rceil = 2\text{팩}$$


* 실제 구매량:

$$2\text{팩} \times 6\text{개} = 12\text{개}$$




3. **예상 구매 비용 계산**:

$$\text{구매 팩 수} \times \text{팩당 단가} = 2\text{팩} \times 2,400\text{원} = 4,800\text{원}$$


4. **사용 후 잔여량 계산**:

$$\text{사용 후 잔여량} = (\text{보유량} + \text{구매량}) - \text{소요량}$$


$$(10\text{개} + 12\text{개}) - 17\text{개} = 22\text{개} - 17\text{개} = 5\text{개}$$
