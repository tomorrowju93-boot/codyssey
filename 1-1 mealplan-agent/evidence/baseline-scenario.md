# 기준 시나리오 (Baseline Scenario)

## 1. 문서 정보

| 항목 | 내용 |
|---|---|
| 프로젝트명 | Weekly Meal Planner AI Agent |
| 미션명 | AI Agent에게 일 제대로 시키는 법 배우기 |
| 과업명 | 일주일 식단 스케줄과 장바구니 아이템 결정 AI Agent |
| 시나리오 버전 | v1.1 |
| 확정일 | 2026-11-24 |
| 실험 ID | EXP-001 |
| 적용 프롬프트 | PROMPT-001 v1.1 (Zero-shot) |

## 2. 과업 정의

가정의 식단 계획 및 식재료 구매 담당자가 매주 반복하는 식단 선정과 장보기 계획 업무를 지원한다. 가족 구성, 식사 일정, 식비 예산, 보유 식재료, 선호 식단 및 조리 가능 시간을 바탕으로 일주일 식단을 수립하고, 필요한 식재료의 소요량과 보유량을 비교하여 장바구니 구매 목록을 결정한다.

- 타겟 사용자: 가정의 식단 계획 및 식재료 구매 담당자
- 수행 주기: 주 1회
- 입력 데이터 형태: 자연어 및 구조화된 텍스트
- 출력 데이터 형태: Markdown 표 및 텍스트

## 3. 공통 입력 조건

| 항목 | 기준값 |
|---|---|
| 가족 구성 | 성인 2명, 자녀 3명 (총 5명) |
| 계획 기간 | 월요일부터 일요일까지 7일 |
| 식재료 구매 예산 | 200,000원 |
| 외식 비용 | 식재료 구매 예산에 포함하지 않음 |
| 식단 범위 | 평일 아침·저녁, 주말 아침·점심·저녁 |
| 선호 식단 | 한식 위주, 일부 양식 포함 |
| 한 끼 최대 조리 시간 | 30분 (식재료 손질부터 한 끼 전체 조리 완료까지) |
| 알레르기 및 제외 식품 | 미확정 |
| 외식 일정 | 토요일 저녁 |
| 식재료 가격표 | 미제공 |

## 4. 주간 식사 일정

| 요일 | 아침 | 점심 | 저녁 |
|---|---|---|---|
| 월요일 | 가정식 | 계획 제외 | 가정식 |
| 화요일 | 가정식 | 계획 제외 | 가정식 |
| 수요일 | 가정식 | 계획 제외 | 가정식 |
| 목요일 | 가정식 | 계획 제외 | 가정식 |
| 금요일 | 가정식 | 계획 제외 | 가정식 |
| 토요일 | 가정식 | 가정식 | 외식 |
| 일요일 | 가정식 | 가정식 | 가정식 |

- 가정식: 총 15끼
- 외식: 1끼
- 계획 제외: 5끼
- 모든 가정식에 가족 5명이 참여한다고 가정하면 총 75인분에 해당한다. 성인과 자녀의 분량 차이는 모델이 사용한 가정을 명시하도록 한다.

## 7. 계산 및 검증 기준

- 추가 필요량 = max(0, 총소요량 - 보유량)
- 실제 구매 수량은 추가 필요량과 구분하고 판매 포장 단위를 고려한다.
- 예상 구매 비용은 품목별 예상 비용의 합계로 계산한다.
- 잔여 예산 = 200,000원 - 예상 구매 비용
- 메뉴별 소요량, 주간 총소요량, 재고 차감 결과 및 장바구니 목록 사이의 정합성을 검토한다.
- 메뉴 선택과 식재료 소요량은 모델마다 달라질 수 있으므로 고정 정답으로 평가하지 않는다.

## 8. 공통 실험 조건

- ChatGPT, Claude, Gemini의 일반 채팅 환경에서 동일한 PROMPT-001 v1.1을 사용한다.
- 신규 채팅에서 페르소나 및 Few-shot 예시 없이 실행한다(Zero-shot).
- 웹 검색 및 외부 도구를 사용하지 않는다.
- 가격은 추정 가격임을 표시한다.
- 알레르기 정보가 미확정이므로 식단은 확정안이 아닌 검토용 초안으로 작성한다.
- 기본 양념류의 상세 품목 및 수량을 확정된 사실로 간주하지 않는다.
- 한국어로 응답한다.
- 모델별 실제 이름, 버전, 추론 설정, 요금제 및 실행 시점을 기록한다.
- 최초 응답 원문은 수정하지 않고 별도 증거 파일에 보존한다.

## 9. 수행 제외 범위

- 온라인 쇼핑몰 실시간 가격 및 재고 확인
- 실제 상품 주문 및 결제
- 질환에 따른 전문적인 영양 처방 및 정확한 영양성분 보장
- 냉장고 재고 자동 인식 및 외부 서비스 자동 연동
