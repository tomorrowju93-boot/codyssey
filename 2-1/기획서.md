# 한국 프로야구 역대 시즌 기록 조회 페이지 기획서

## 1. 대상 사용자

- 한국 프로야구에 관심이 있고 특정 연도의 정규리그 성적과 한국시리즈 결과를 확인하려는 누구나.

## 2. 사용 목적

- 한국 프로야구 원년인 1982년부터 2026년까지 연도를 선택하여 정규리그 최종 순위와 팀별 전적을 확인한다.
- 같은 화면에서 해당 연도의 한국시리즈 우승·준우승 팀, 시리즈 전적, 경기별 날짜와 점수를 확인한다.
- 공식 기록에 근거한 정보를 제공하고, 미확정 기록이나 확인되지 않은 값을 추정하여 표시하지 않는다.

## 3. 화면 구성과 동작

### 3.1 첫 화면과 Hero 섹션

- 상단 Hero에 서비스 제목, 소개 문구, 조회 범위를 표시한다.
- 소개 문구 예시: ‘1982년부터 2026년까지, 한국 프로야구의 시즌 순위와 한국시리즈 기록을 한눈에 확인하세요.’
- Hero 아래에 연도 선택과 기록 조회 영역을 배치한다. 최초 선택 연도는 2026년이다.
- 화면 문구는 한국어로 제공한다.

### 3.2 연도 선택

- 1982~2026년의 45개 연도를 빠짐없이 선택할 수 있는 선택 상자를 제공한다.
- 연도를 선택하면 추가 조회 버튼 없이 아래의 정규리그 표와 한국시리즈 결과가 함께 바뀐다.
- 각 영역의 제목에 선택 연도를 표시하여 서로 다른 연도의 기록을 혼동하지 않도록 한다.

### 3.3 정규리그 순위와 종합 전적

- 연도 선택 아래에 ‘선택 연도 정규리그 최종 순위’를 표시한다.
- 종합 전적은 해당 시즌의 팀별 정규리그 전적을 의미하며, 한국시리즈 등 포스트시즌 경기 전적을 합산하지 않는다.
- 표 항목은 다음 순서로 구성한다.

| 항목 | 표시 내용 |
|---|---|
| 순위 | 공식 정규리그 순위 |
| 팀명 | 해당 연도 당시 구단명 |
| 경기 수 | 공식 정규리그 경기 수 |
| 승 | 승리 수 |
| 무 | 무승부 수 |
| 패 | 패배 수 |
| 승률 | 해당 시즌 공식 기록의 승률과 표시 정밀도 |
| 게임 차 | 공식 기록으로 확인한 선두와의 게임 차 |

- 포스트시즌을 반영한 종합 최종 순위를 정규리그 순위로 대신 사용하지 않는다.
- 전·후기 또는 양대 리그 등 시즌 운영 방식이 다른 경우, 당시 공식 기록의 구분을 소제목과 표에 반영한다. 구분별 전적을 설명 없이 하나의 순위로 합치지 않는다.
- 공식 값이 없는 게임 차 등 개별 항목은 ‘—’와 사유로 표시하고, 현재 규칙으로 임의 재계산하지 않는다.

### 3.4 한국시리즈 결과

- 정규리그 표 아래에 한국시리즈 결과 영역을 배치한다.
- 우승 팀과 준우승 팀은 당시 팀명과 로고 이미지로 표시하고, 시리즈 전적은 두 팀 중 어느 팀 기준인지 명시하여 승·무·패를 표시한다.
- 경기별 결과는 ‘차전·날짜·팀 1·팀 1 점수·팀 2 점수·팀 2’ 표로 구성한다. 팀명과 점수의 대응 관계가 명확해야 한다.
- 날짜는 YYYY-MM-DD 형식으로 표시한다. 실제 개최된 경기 결과를 차전 순서대로 표시하며 무승부 경기도 누락하지 않는다.
- 한국시리즈가 열리지 않은 시즌은 ‘한국시리즈 미개최’와 공식 자료로 확인한 설명을 표시한다. 해당 시즌의 우승 결정 방식은 별도 설명으로 제공하며, 가상의 준우승 팀이나 경기 결과를 만들지 않는다.

### 3.5 기록 상태와 출처 표시

- 공식 결과가 확정되지 않은 항목은 ‘미확정’, 아직 공식 자료 대조가 끝나지 않은 항목은 ‘자료 확인 중’, 공식적으로 해당 값이 없는 경우는 ‘해당 없음’ 또는 ‘—’로 구분한다.
- 미확정·자료 확인 중인 값에 0, 임의 팀명, 추정 점수를 넣지 않는다. 다른 연도의 값을 그대로 남겨두지 않는다.
- 확인된 항목은 표시하되, 일부 경기 기록을 확인한 것만으로 해당 연도 전체 검증이 완료됐다고 표시하지 않는다.
- 선택 연도에 대응하는 공식 출처 링크, 자료 확인일, 기록 상태를 제공한다. 연감은 발행 연도와 해당 쪽수도 함께 기록한다.

### 3.6 로고와 좁은 화면

- 한국시리즈 팀 로고는 해당 연도 당시 로고를 우선 사용하고, HTTPS 이미지 주소로 삽입한다. 인터넷 연결을 전제로 한다.
- 해당 연도 로고나 사용 권한을 확인할 수 없거나 이미지 로딩에 실패하면 팀명을 표시한다. 현재 로고를 과거 로고처럼 대신 표시하지 않는다.
- 팀명은 로고와 함께 텍스트로 제공하며, 로고가 없어도 우승·준우승 팀을 확인할 수 있다.
- 좁은 화면에서는 내용을 세로로 재배치한다. 표가 넓으면 표 영역 안에서 가로 스크롤하여 모든 열을 볼 수 있도록 하고, 페이지 오른쪽 내용이 접근 불가능하게 잘리지 않게 한다.

## 4. 필요한 자료

### 4.1 시즌 기록

- 1982~2026년 정규리그 최종 순위, 팀별 전적, 시즌 운영 방식.
- 해당 기간 한국시리즈 우승·준우승 팀과 시리즈 전적, 경기별 날짜·대진·점수 및 미개최 사유.
- 자료는 제작 과정에서 공식 출처와 대조해 HTML 내부에 포함한다. 조회 시에는 기록 API를 호출하지 않는다.
- 공식 자료 확인 경로:
  - KBO 연도별 팀 순위: https://www.koreabaseball.com/Record/TeamRank/TeamRank.aspx
  - KBO 경기일정·결과: https://www.koreabaseball.com/Schedule/Schedule.aspx
  - KBO 역대 구단성적: https://www.koreabaseball.com/Record/History/Team/Record.aspx
  - 위 경로만으로 확인되지 않는 오래된 경기별 기록과 시즌 제도는 KBO 공식 연감·기록 자료로 보완한다. 사용한 자료의 정확한 문서명, URL, 연도, 쪽수와 확인일을 기록한다.
- 위 URL은 자료 수집 경로이며, 현재 기획 단계에서 45개 시즌의 기록을 모두 수집·검증했다는 의미는 아니다. 실제 기록 수집과 대조는 후속 제작 단계에서 수행한다.
- 기록의 출처 표기와 공개·재이용 조건을 제작 단계에서 확인한다. 공식 사이트에 공개되어 있다는 이유만으로 자유 이용이 허용된 것으로 기록하지 않는다.

### 4.2 팀 로고 및 기타 외부 자료

- 우선 출처: 해당 구단 공식 홈페이지의 구단 소개·역사·브랜드 자료, KBO 공식 구단 관련 자료.
- 로고별로 구단명, 적용 연도, 출처 페이지 URL, HTTPS 이미지 URL, 권리자, 사용 조건·허락 근거, 확인일을 기록한다.
- 현재 구체적인 로고 URL과 사용 권한은 미확정이다. 사용 가능함이 확인된 로고만 채택하며, 확인이 어려운 것은 팀명으로 대체한다.
- 장식 사진, 외부 웹폰트, 외부 JavaScript·CSS 라이브러리는 사용하지 않는다. 시스템 글꼴과 HTML 내부 CSS·JavaScript로 구현한다.

## 5. 필수 기능과 추가 기능

### 필수 기능 — 이번 HTML 구현 범위

- 서비스 소개 Hero와 기본 선택 연도 2026년 표시.
- 1982~2026년 연도 선택 및 해당 연도의 정규리그·한국시리즈 결과 동시 갱신.
- 정규리그 순위와 팀별 전적 표, 한국시리즈 요약과 경기별 결과 표.
- 당시 팀 로고 우선 표시 및 실패 시 팀명 대체.
- 특수한 시즌의 공식 구분, 미개최·미확정·자료 확인 중 상태 안내.
- 공식 출처·자료 확인일 표시와 좁은 화면 대응.
- 기록 데이터를 포함한 HTML 한 장 실행. 로그인·API 키·서버 실행 불필요.

### 추가 기능 — 이번 구현에서는 제외

- 특정 팀의 역대 성적을 모아 조회하는 기능.
- 두 개 이상 연도를 나란히 비교하는 기능.

## 6. 완료 기준

1. HTML 파일을 브라우저에서 열면 상단에 서비스 소개 Hero가 보이고, 그 아래 연도 선택 상자에 2026년이 선택되어 있다.
2. 연도 선택 상자에서 1982~2026년의 45개 연도를 빠짐없이 선택할 수 있다.
3. 다른 연도를 선택하면 정규리그 표와 한국시리즈 결과의 제목·내용·출처·상태가 선택 연도에 맞게 함께 바뀐다.
4. 정규리그 표에서 순위·팀명·경기 수·승·무·패·승률·게임 차를 확인할 수 있다. 공식 기록에서 제공하지 않는 항목은 값 대신 ‘—’와 사유를 확인할 수 있다.
5. 특수한 시즌을 선택하면 당시 공식 구분에 따른 표와 설명이 나타나고, 일반 시즌의 표를 잘못 재사용하지 않는다.
6. 한국시리즈 개최 및 결과가 확인된 연도를 선택하면 우승·준우승 팀, 기준 팀이 명시된 시리즈 전적, 실제 경기별 날짜와 점수를 확인할 수 있다. 무승부 경기도 표시된다.
7. 한국시리즈 미개최 시즌을 선택하면 미개최 안내와 확인된 설명이 나오고, 경기 결과나 준우승 팀을 임의로 표시하지 않는다.
8. 미확정 또는 자료 확인 중인 항목을 선택하면 해당 상태가 나오고, 추정값이나 다른 연도 기록이 표시되지 않는다. 확인된 과거 기록의 미수집 상태를 최종 완성으로 간주하지 않는다.
9. 해당 연도의 사용 가능한 팀 로고가 있으면 표시된다. 이미지 주소를 일시적으로 잘못 바꾸거나 이미지 요청을 차단하면 깨진 이미지 대신 팀명을 볼 수 있다.
10. 360px 폭의 화면에서 연도 선택과 모든 구역에 접근할 수 있고, 넓은 표의 마지막 열은 표 내부 가로 스크롤로 확인할 수 있다.
11. 출처 링크를 누르면 기록 확인에 사용한 공식 자료가 새 탭에서 열린다. 연감 자료는 함께 표시된 문서명과 쪽수로 대조할 수 있다.
12. 별도 로컬 파일·로그인·API 키·서버 없이 HTML 한 장으로 화면과 내장 기록 조회가 동작한다. 인터넷 연결이 끊겨도 내장 기록 조회는 동작하고, 로고는 팀명으로 대체된다. 외부 출처 페이지 열람은 인터넷 연결이 필요하다.
13. 아래 검증 절차로 표시된 기록을 공식 자료와 대조했을 때 일치한다. 전체 45개 시즌의 자료 대조 여부와 미확정 항목을 구분해 기록한다.

## 7. 한계 및 비목표 — 3가지

1. 기록은 HTML에 포함된 자료로 한정하며 자동 갱신하지 않는다. 새로운 확정 결과나 기록 정정은 공식 자료를 재확인하여 HTML 데이터를 수동 수정해야 한다.
2. 로그인, 개인 기록 저장, 실시간 경기 조회, API 연결, 챗봇·AI 기능은 이번 구현 범위에 포함하지 않는다.
3. 로고는 인터넷 연결, 이미지 제공처 상태 및 사용 권한 확인 여부에 따라 표시되지 않을 수 있다. 이 경우 팀명으로 대체하며, 모든 연도의 당시 로고 제공을 보장하지 않는다.

## 8. 정확성 검증 방법 — 공식 기록과 항목별 대조

- 비교 대상: KBO 공식 팀 순위·경기 결과·공식 연감 등 해당 연도의 원자료.
- 절차:
  1. 데이터 정리 시 각 연도의 출처 URL, 자료 확인일, 기록 상태를 남긴다.
  2. 일반 시즌, 전·후기나 양대 리그 등 특수 시즌, 한국시리즈 미개최 시즌을 포함해 우선 대조한다. 1982년과 2026년도 확인 대상에 포함한다. 특수·미개최 여부는 공식 자료 확인 후 정한다.
  3. 연도를 선택하고 정규리그의 모든 팀 행을 공식 표와 비교한다. 순위·팀명·경기 수·승·무·패·승률·게임 차와 구분 제목을 각각 확인한다. 포스트시즌 반영 순위와 혼동하지 않았는지도 확인한다.
  4. 한국시리즈 우승·준우승 팀과 시리즈 전적을 확인하고, 실제 경기별 날짜·대진·점수·무승부를 공식 결과와 비교한다.
  5. 같은 절차를 45개 시즌 전체에 적용한다. 불일치는 원자료를 재확인해 수정하고, 미확정·자료 확인 중 항목은 그 사유를 남긴다. 확정 기록의 대조가 끝나지 않으면 기록 정확성 검증 완료로 표시하지 않는다.
- 승률과 게임 차는 현재 규칙으로 재계산한 값을 정답으로 삼지 않고 해당 시즌 공식 값을 기준으로 한다.

- 모델 이름: GPT-6 계열. 이 대화에서 사용자 화면의 정확한 세부 모델 표기는 확인되지 않았으므로 제출 전 실제 표시된 모델 이름을 확인하여 기입한다.
- 활용 과정: AI의 질문에 답하며 대상 사용자, 조회 범위, 표 항목, 한국시리즈 상세 범위, Hero 구성, 로고 대체 방식, 필수·추가 기능, 한계 및 검증 방법을 정함. AI가 작성한 내용이 의도에 맞는지 사용자가 검토함.
