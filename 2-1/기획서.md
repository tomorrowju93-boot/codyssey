# 한국 프로야구 역대 시즌 기록 조회 페이지 기획서

## 1. 대상 사용자

- 한국 프로야구에 관심이 있고 특정 연도의 정규리그 성적과 한국시리즈 결과를 확인하려는 누구나.

## 2. 사용 목적

- 한국 프로야구 원년인 1982년부터 2026년까지 연도를 선택하여 정규리그 최종 순위와 팀별 전적을 확인한다.
- 같은 화면에서 해당 연도의 한국시리즈 우승·준우승 팀, 시리즈 전적, 경기별 날짜와 점수를 확인한다.
- 공식 기록에 근거한 정보를 제공하고, 미확정 기록이나 확인되지 않은 값을 추정하여 표시하지 않는다.

## 3. 화면 구성과 동작

### 3.1 첫 화면과 Hero 섹션

- 상단 Hero에 서비스 제목, 소개 문구, 조회 범위를 표시한다.
- 소개 문구 예시: ‘1982년부터 2026년까지, 한국 프로야구의 시즌 순위와 한국시리즈 기록을 한눈에 확인하세요.’
- Hero 아래에 연도 선택과 기록 조회 영역을 배치한다. 최초 선택 연도는 2026년이다.
- 화면 문구는 한국어로 제공한다.

### 3.2 연도 선택

- 1982~2026년의 45개 연도를 빠짐없이 선택할 수 있는 선택 상자를 제공한다.
- 연도를 선택하면 추가 조회 버튼 없이 아래의 정규리그 표와 한국시리즈 결과가 함께 바뀐다.
- 각 영역의 제목에 선택 연도를 표시하여 서로 다른 연도의 기록을 혼동하지 않도록 한다.

### 3.3 정규리그 순위와 종합 전적

- 연도 선택 아래에 ‘선택 연도 정규리그 최종 순위’를 표시한다.
- 종합 전적은 해당 시즌의 팀별 정규리그 전적을 의미하며, 한국시리즈 등 포스트시즌 경기 전적을 합산하지 않는다.
- 표 항목은 다음 순서로 구성한다.

| 항목 | 표시 내용 |
|---|---|
| 순위 | 공식 정규리그 순위 |
| 팀명 | 해당 연도 당시 구단명 |
| 경기 수 | 공식 정규리그 경기 수 |
| 승 | 승리 수 |
| 무 | 무승부 수 |
| 패 | 패배 수 |
| 승률 | 해당 시즌 공식 기록의 승률과 표시 정밀도 |
| 게임 차 | 공식 기록으로 확인한 선두와의 게임 차 |

- 포스트시즌을 반영한 종합 최종 순위를 정규리그 순위로 대신 사용하지 않는다.
- 시즌 유형별 표 구성은 아래 기준을 적용한다. 해당 연도의 유형과 구분 명칭은 공식 자료로 확인한 뒤 데이터에 명시한다.

| 시즌 유형 | 표시할 표와 순서 | 순위·게임 차 처리 |
|---|---|---|
| 단일 리그 | 정규리그 최종 순위 표 1개 | 해당 연도 공식 정규리그 순위와 게임 차를 사용 |
| 전·후기 리그 | ‘전기리그 순위’ 다음 ‘후기리그 순위’를 각각 표시. 공식 자료에 연간 정규리그 합산 전적이 있으면 ‘연간 합산 전적(참고)’을 추가 | 각 기별 공식 순위와 게임 차를 사용. 합산 전적으로 임의 통합 순위를 만들지 않음 |
| 양대 리그 | 공식 리그 명칭으로 표 2개를 분리하고 공식 자료의 구분 순서대로 표시 | 각 리그 안의 공식 순위와 게임 차를 사용. 두 리그를 합친 임의 순위는 만들지 않음 |

- 특수 시즌에서는 영역 제목을 ‘선택 연도 정규리그 성적 — 전·후기 리그’ 또는 ‘선택 연도 정규리그 성적 — 양대 리그’로 표시한다. 각 표 위에 적용 구분과 순위 기준을 안내한다.
- 공식 연간 합산 전적을 참고로 표시할 때 순위·게임 차가 공식적으로 제공되지 않으면 해당 열은 ‘—’와 사유를 표시한다. 한국시리즈 성적을 반영한 종합 순위로 채우지 않는다.
- 공식 값이 없는 게임 차 등 개별 항목은 ‘—’와 사유로 표시하고, 현재 규칙으로 임의 재계산하지 않는다.

### 3.4 한국시리즈 결과

- 정규리그 표 아래에 한국시리즈 결과 영역을 배치한다.
- 우승 팀과 준우승 팀은 해당 연도 당시 팀명을 텍스트로 표시한다. 로고 이미지는 이번 구현에서 사용하지 않는다. 시리즈 전적은 우승 팀 기준임을 명시하고 승·무·패를 표시한다.
- 경기별 결과는 ‘차전·날짜·팀 1·팀 1 점수·팀 2 점수·팀 2’ 표로 구성한다. 팀명과 점수의 대응 관계가 명확해야 한다.
- 날짜는 YYYY-MM-DD 형식으로 표시한다. 실제 개최된 경기 결과를 차전 순서대로 표시하며 무승부 경기도 누락하지 않는다.
- 한국시리즈가 열리지 않은 시즌은 ‘한국시리즈 미개최’와 공식 자료로 확인한 설명을 표시한다. 해당 시즌의 우승 결정 방식은 별도 설명으로 제공하며, 가상의 준우승 팀이나 경기 결과를 만들지 않는다.

### 3.5 기록 상태와 출처 표시

- 공식 결과가 확정되지 않은 항목은 ‘미확정’, 아직 공식 자료 대조가 끝나지 않은 항목은 ‘자료 확인 중’, 공식적으로 해당 값이 없는 경우는 ‘해당 없음’ 또는 ‘—’로 구분한다.
- 미확정·자료 확인 중인 값에 0, 임의 팀명, 추정 점수를 넣지 않는다. 다른 연도의 값을 그대로 남겨두지 않는다.
- 확인된 항목은 표시하되, 일부 경기 기록을 확인한 것만으로 해당 연도 전체 검증이 완료됐다고 표시하지 않는다.
- 선택 연도에 대응하는 공식 출처 링크, 자료 확인일, 기록 상태를 제공한다. 연감은 발행 연도와 해당 쪽수도 함께 기록한다.

### 3.6 팀명 표시와 좁은 화면

- 정규리그 표, 한국시리즈 요약 및 경기 결과 표에서 해당 연도 당시 팀명을 텍스트로 표시한다.
- 로고 이미지나 이미지 로딩 대체 처리는 구현하지 않는다. 팀명 표시와 내장 기록 조회는 이미지 제공처 및 인터넷 연결에 의존하지 않는다.
- 좁은 화면에서는 내용을 세로로 재배치한다. 표가 넓으면 표 영역 안에서 가로 스크롤하여 모든 열을 볼 수 있도록 하고, 페이지 오른쪽 내용이 접근 불가능하게 잘리지 않게 한다.

## 4. 필요한 자료

### 4.1 시즌 기록

- 1982~2026년 정규리그 최종 순위, 팀별 전적, 시즌 운영 방식.
- 해당 기간 한국시리즈 우승·준우승 팀과 시리즈 전적, 경기별 날짜·대진·점수 및 미개최 사유.
- 자료는 제작 과정에서 공식 출처와 대조해 HTML 내부에 포함한다. 조회 시에는 기록 API를 호출하지 않는다.
- 공식 자료 확인 경로:
  - KBO 연도별 팀 순위: https://www.koreabaseball.com/Record/TeamRank/TeamRank.aspx
  - KBO 경기일정·결과: https://www.koreabaseball.com/Schedule/Schedule.aspx
  - KBO 역대 구단성적: https://www.koreabaseball.com/Record/History/Team/Record.aspx
  - 위 경로만으로 확인되지 않는 오래된 경기별 기록과 시즌 제도는 KBO 공식 연감·기록 자료로 보완한다. 사용한 자료의 정확한 문서명, URL, 연도, 쪽수와 확인일을 기록한다.
- 위 URL은 자료 수집 경로이며, 현재 기획 단계에서 45개 시즌의 기록을 모두 수집·검증했다는 의미는 아니다. 실제 기록 수집과 대조는 후속 제작 단계에서 수행한다.
- 기록의 출처 표기와 공개·재이용 조건을 제작 단계에서 확인한다. 공식 사이트에 공개되어 있다는 이유만으로 자유 이용이 허용된 것으로 기록하지 않는다.

### 4.2 이미지·글꼴·라이브러리 사용 범위

- 팀 로고와 장식 사진은 사용하지 않으며, 팀은 당시 팀명 텍스트로 식별한다.
- 외부 웹폰트와 외부 JavaScript·CSS 라이브러리는 사용하지 않는다. 시스템 글꼴과 HTML 내부 CSS·JavaScript로 구현한다.
- 외부 이미지·글꼴·라이브러리에 대한 출처·사용 권한 항목은 이번 범위에 해당하지 않는다. 시즌 기록의 출처 표기와 재이용 조건 확인은 4.1의 방침에 따라 별도로 수행한다.

### 4.3 공식 자료가 다를 때의 처리 원칙

1. 먼저 같은 연도·같은 리그 구분·같은 집계 범위를 비교했는지 확인한다. 정규리그 순위와 포스트시즌 반영 종합 순위는 서로 다른 자료이므로 충돌로 취급하지 않는다.
2. 같은 항목에 대한 KBO 공식 정정 공지나 수정 기록이 있으면, 그 정정 대상과 적용 범위를 확인하여 우선 반영한다.
3. 정정 안내가 없으면 정규리그 순위·전적은 해당 연도 KBO 팀 순위 자료, 경기별 날짜·점수는 KBO 공식 경기 결과를 우선 확인한다. 오래된 연도의 해당 정보가 없거나 구분이 불명확하면 KBO 공식 연감·기록 자료로 보완한다.
4. 단순히 최신 문서라는 이유로 다른 집계 범위의 값을 채택하지 않는다. 같은 범위의 공식 자료끼리 차이가 남으면 값을 임의 선택하지 않고 해당 항목을 ‘자료 확인 중’으로 표시한다. 비교한 문서명·URL·쪽수·불일치 내용을 남기고 확인 후 반영한다.

## 5. 필수 기능과 추가 기능

### 필수 기능 — 이번 HTML 구현 범위

- 서비스 소개 Hero와 기본 선택 연도 2026년 표시.
- 1982~2026년 연도 선택 및 해당 연도의 정규리그·한국시리즈 결과 동시 갱신.
- 정규리그 순위와 팀별 전적 표, 한국시리즈 요약과 경기별 결과 표.
- 해당 연도 당시 팀명을 텍스트로 표시. 로고 이미지 미사용.
- 특수한 시즌의 공식 구분, 미개최·미확정·자료 확인 중 상태 안내.
- 공식 출처·자료 확인일 표시와 좁은 화면 대응.
- 기록 데이터를 포함한 HTML 한 장 실행. 로그인·API 키·서버 실행 불필요.

### 추가 기능 — 이번 구현에서는 제외

- 특정 팀의 역대 성적을 모아 조회하는 기능.
- 두 개 이상 연도를 나란히 비교하는 기능.

## 6. 완료 기준

1. HTML 파일을 브라우저에서 열면 상단에 서비스 소개 Hero가 보이고, 그 아래 연도 선택 상자에 2026년이 선택되어 있다.
2. 연도 선택 상자에서 1982~2026년의 45개 연도를 빠짐없이 선택할 수 있다.
3. 다른 연도를 선택하면 정규리그 표와 한국시리즈 결과의 제목·내용·출처·상태가 선택 연도에 맞게 함께 바뀐다.
4. 정규리그 표에서 순위·팀명·경기 수·승·무·패·승률·게임 차를 확인할 수 있다. 공식 기록에서 제공하지 않는 항목은 값 대신 ‘—’와 사유를 확인할 수 있다.
5. 전·후기 시즌을 선택하면 전기·후기 표가 각각 나오고, 양대 리그 시즌을 선택하면 당시 공식 리그명으로 표가 나뉜다. 순위·게임 차는 각 구분 안의 공식 값을 사용한다. 연간 합산 전적은 공식 자료가 있을 때만 참고로 표시하고 임의 통합 순위를 만들지 않는다.
6. 한국시리즈 개최 및 결과가 확인된 연도를 선택하면 우승·준우승 팀, 기준 팀이 명시된 시리즈 전적, 실제 경기별 날짜와 점수를 확인할 수 있다. 무승부 경기도 표시된다.
7. 한국시리즈 미개최 시즌을 선택하면 미개최 안내와 확인된 설명이 나오고, 경기 결과나 준우승 팀을 임의로 표시하지 않는다.
8. 미확정 또는 자료 확인 중인 항목을 선택하면 해당 상태가 나오고, 추정값이나 다른 연도 기록이 표시되지 않는다. 확인된 과거 기록의 미수집 상태를 최종 완성으로 간주하지 않는다.
9. 연도를 바꾸면 정규리그 표와 한국시리즈 결과에 해당 연도 당시 팀명이 텍스트로 나타난다. 팀 로고나 이미지 요청 없이도 팀을 식별할 수 있다.
10. 360px 폭의 화면에서 연도 선택과 모든 구역에 접근할 수 있고, 넓은 표의 마지막 열은 표 내부 가로 스크롤로 확인할 수 있다.
11. 출처 링크를 누르면 기록 확인에 사용한 공식 자료가 새 탭에서 열린다. 연감 자료는 함께 표시된 문서명과 쪽수로 대조할 수 있다.
12. 별도 로컬 파일·로그인·API 키·서버 없이 HTML 한 장으로 화면과 내장 기록 조회가 동작한다. 브라우저를 오프라인 상태로 전환한 뒤 파일을 다시 열어도 Hero·연도 선택·팀명·내장 기록 조회가 동작한다. 외부 출처 페이지 열람은 인터넷 연결이 필요하다.
13. 아래 검증 절차로 표시된 기록을 공식 자료와 대조했을 때 일치한다. 전체 45개 시즌의 자료 대조 여부와 미확정 항목을 구분해 기록한다.

## 7. 한계 및 비목표

### 7.1 한계 — 3가지

1. 조회 범위는 1982년부터 2026년까지이며, HTML에 수록된 기록만 조회할 수 있다. 이후 연도는 제공하지 않는다.
2. 기록은 자동으로 갱신되지 않는다. 새로운 확정 결과나 공식 기록 정정은 공식 자료를 확인한 뒤 HTML 내부 데이터를 수동으로 수정해야 한다.
3. 내장 기록은 오프라인에서도 조회할 수 있지만, 공식 출처 링크의 외부 자료를 열어 확인하려면 인터넷 연결이 필요하다.

### 7.2 비목표 — 3가지

1. 로그인·회원 관리·개인별 조회 기록 저장 기능은 구현하지 않는다.
2. 실시간 경기 조회·외부 API 연결·챗봇·AI 기능은 구현하지 않는다.
3. 구단 로고·사진·외부 웹폰트·외부 라이브러리는 사용하지 않는다. 구단은 해당 연도 당시 팀명 텍스트로 표시한다.

## 8. 정확성 검증 방법 — KBO 공식 기록과 항목별 대조

- 비교 대상: 조회 연도에 해당하는 KBO 공식 팀 순위, 경기 결과 및 공식 연감·기록 자료.
- 검증 절차:
  1. HTML을 브라우저에서 열고 확인할 연도를 선택한다.
  2. 같은 연도의 공식 자료를 열고 연도·리그 구분·집계 범위가 같은지 확인한다. 정규리그 순위와 포스트시즌을 반영한 시즌 최종 순위를 구분한다.
  3. 정규리그 표의 모든 팀에 대해 순위·팀명·경기 수·승·무·패·승률·게임 차를 공식 자료와 비교한다. 전·후기 및 양대 리그는 각 구분별로 비교한다.
  4. 한국시리즈 우승·준우승 팀, 시리즈 전적, 경기별 날짜·대진·점수·무승부를 공식 자료와 비교한다. 미개최 시즌은 개최되지 않은 사유를 확인한다.
  5. 같은 절차를 1982~2026년의 45개 시즌에 적용한다. 출처 URL, 연감의 문서명·쪽수, 확인일, 예상 결과, 실제 결과, 일치 여부를 기록한다.
- 판정 기준: 표시된 기록이 같은 집계 범위의 공식 자료와 일치하면 통과한다. 불일치하거나 공식 자료를 확인하지 못한 항목은 확인 상태와 사유를 기록하고, 검증 완료로 처리하지 않는다.
- 승률과 게임 차는 현재 규칙으로 임의 재계산하지 않고 해당 시즌 공식 값을 기준으로 비교한다.
