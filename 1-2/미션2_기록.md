# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT / chatgpt_screenshot.png
- 좁혀서 적은 한 문장: ‘센과 치히로의 행방불명’, ‘어벤져스: 엔드게임’, ‘토이 스토리’ 영화는 카드 선택과 드래그 이동이 모두 되지 않는다.
- 좁히려고 해 본 것과 결과:
  - 처음 영화 8개를 확인한 결과, ‘센과 치히로의 행방불명’, ‘어벤져스: 엔드게임’, ‘토이 스토리’는 드래그로 이동되지 않고 카드를 눌러도 선택되지 않았음.
  - 나머지 영화와 새로 추가한 영화는 드래그로 이동과 카드를 누르고 이동 잘 됨. 새로 추가한 영화의 제목은 기록하지 않았음.
  - 이동한 영화가 다른 칸에 중복으로 남지 않는 것, 영화 추가, 파일을 다시 열었을 때 저장 유지, 좁은 화면 표시, ‘처음으로’, HTML 단독 실행, 빈 제목·공백만 입력했을 때 안내는 정상 동작하는 것으로 확인했음.
  - AI는 ‘테스트영화’와 ‘테스트 영화’를 각각 추가해 선택과 드래그 이동을 비교하도록 제안했음. 이 추가 실험의 직접 확인 결과는 '테스트영화'는 드래그와 카드를 누르고 이동 가능함을 확인했고 '테스트 영화'는 두가지 테스트 모두 안됨.
- AI가 말한 원인과, 그 설명을 직접 확인한 결과:
  - 원인 설명: 영화 제목을 카드의 이름표로 사용하는데, 이름표를 HTML 문자열에 넣을 때 따옴표로 감싸지 않아 공백 뒤의 제목이 잘림. 예를 들어 ‘토이 스토리’의 이름표가 ‘토이’가 되어 원래 영화와 연결되지 않음.
  - 직접 확인한 결과: 앞서 관찰한 이동 불가 영화 3편은 모두 제목에 공백이 있다는 설명과 일치함.
