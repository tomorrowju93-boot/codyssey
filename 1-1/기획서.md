# 영화 티어리스트 웹페이지 기획서

## 누가 쓰나

- 나 혼자 사용하는 개인용 웹페이지입니다.

## 무엇을 하려고

- 본 영화를 내 취향에 따라 평가하고 순위를 정리합니다.
- 영화를 S·A·B·C·D의 다섯 등급으로 분류합니다.

## 화면과 동작

- 한 화면에서 영화 입력·추가, 등급 선택·변경, 수정·삭제, 티어별 결과 확인을 합니다.
- 저장된 기록이 없는 최초 실행 시 기본 영화 10편을 '미 분류' 영역에 표시합니다. 다시 열 때는 저장된 영화 목록과 등급을 불러옵니다.
- 사용자가 입력 상자에 영화 제목을 입력하면 해당 제목의 영화 항목을 생성합니다. 외부 서비스 API를 사용하지 않습니다.
- 새로 추가한 영화와 등급이 지정되지 않은 영화는 '미 분류' 영역에서 관리합니다.
- 영화마다 등급을 선택하거나 변경합니다.
- 영화를 다른 등급 영역으로 드래그앤드롭하면 해당 등급으로 변경됩니다.
- 모바일에서는 영화 항목을 손가락으로 꾹 누른 뒤 원하는 영역으로 이동하여 놓습니다.
- 추가한 영화 정보를 수정할 수 있습니다. 구체적인 수정 항목은 아직 정하지 않았습니다.
- 목록에서 영화를 삭제합니다.
- 영화는 선택한 등급에 따라 티어별로 표시합니다.
- S·A·B·C·D 등급별 영역은 서로 다른 색으로 구분합니다.
- 로그인 없이 현재 브라우저에 영화 목록과 등급을 저장합니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화 목록과 등급이 유지됩니다.
- PC와 모바일에 대응하는 밝고 단정한 화면으로 만듭니다.

## 필요한 자료

- 기본 영화 목록은 다음 10편입니다.
  - 오디세이
  - 인터스텔라
  - 인셉션
  - 라라랜드
  - 극한직업
  - 명량
  - 듄
  - 인턴
  - 악마는 프라다를 입는다
  - 웡카
- 기본 목록 외에 사용자가 직접 입력하는 영화 제목을 사용합니다.
- 외부 영화 데이터 서비스와 API 키는 사용하지 않습니다.
- 영화 포스터는 사용하지 않습니다. 외부 영화 정보·포스터를 가져오는 API 연결 작업을 생략하여 간단하고 빠르게 만들기 위한 결정입니다.

## 완성 기준

- 저장된 기록이 없는 상태에서 처음 열면 기본 영화 10편이 모두 '미 분류' 영역에 표시됩니다.
- 기본 영화도 등급 변경·수정·삭제가 가능하며, 다시 열어도 저장된 변경 사항이 유지됩니다.
- 입력 상자에 영화 제목을 입력하면 외부 서비스 API 호출 없이 해당 제목의 영화 항목이 생성됩니다.
- 새로 추가한 영화와 등급이 지정되지 않은 영화가 '미 분류' 영역에 표시됩니다.
- 영화에 S·A·B·C·D 중 하나를 선택하면 해당 티어에 표시됩니다.
- 영화의 등급을 변경하면 변경한 티어에 표시됩니다.
- 영화를 다른 등급 영역으로 드래그앤드롭하면 해당 영역으로 이동하고 등급이 변경됩니다.
- 모바일 Chrome에서 영화 항목을 손가락으로 꾹 누른 뒤 다른 등급 영역으로 이동하여 놓으면 해당 등급으로 변경됩니다.
- 영화 정보를 수정하면 변경한 내용이 화면에 반영됩니다. 구체적인 검증 항목은 수정 항목을 정한 뒤 확정합니다.
- 영화를 삭제하면 내 목록과 티어별 결과에서 사라집니다.
- S·A·B·C·D의 다섯 등급 영역이 서로 다른 색으로 표시됩니다.
- 영화에 등급을 지정한 뒤 새로고침해도 영화 목록과 지정한 등급이 남습니다.
- 파일을 닫고 같은 브라우저에서 같은 파일을 다시 열어도 영화 목록과 지정한 등급이 남습니다.
- 영화 수정·삭제 및 드래그앤드롭으로 변경한 등급도 같은 브라우저에서 같은 파일을 다시 열었을 때 유지됩니다.
- 데스크톱 및 모바일의 Chrome 브라우저에서 영화 입력·추가, 등급 선택·변경, 수정·삭제와 티어별 결과 확인이 가능합니다.
