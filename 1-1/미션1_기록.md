- AI B Gemini / 대화 공유 링크 또는 캡처 파일명: 사용한 AI 모델명 Gemini / [gemini_screenshot.png](gemini_screenshot.png). 사용한 AI와의 요청·답변 내용을 스크린샷으로 첨부했습니다.
- AI가 물어서 내가 정한 것: 나 혼자 사용하는 개인용 페이지에서 본 영화의 순위를 정리하기로 했습니다. 등급은 S·A·B·C·D로 정하고, 영화마다 등급을 선택하며 한 화면에서 입력과 결과 확인을 하기로 했습니다. 로그인 없이 현재 브라우저에 저장하고, PC와 모바일에 대응하는 밝고 단정한 디자인으로 정했습니다. 첫 버전의 범위는 영화 추가, 등급 선택·변경, 삭제, 티어별 표시와 저장 등 핵심 기능으로 정했습니다.
질문에 답한 뒤 직접 추가·변경한 요구사항도 기획서에 반영했습니다. 처음에는 영화 검색으로 추가하는 방식을 골랐으나, 간단하고 빠르게 만들기 위해 외부 API와 포스터를 사용하지 않고 제목을 직접 입력하는 방식으로 변경했습니다. 드래그앤드롭, 영화 수정·삭제, 등급별 색상 구분, '미 분류' 영역과 다시 열어도 기록이 유지되는 조건을 추가했습니다. 확인 환경은 데스크톱·모바일 Chrome으로 정했고, 모바일에서는 꾹 누른 뒤 이동하도록 했습니다. 기본 영화는 오디세이, 인터스텔라, 인셉션, 라라랜드, 극한직업, 명량, 듄, 인턴, 악마는 프라다를 입는다, 웡카의 10편으로 정했습니다.
- 샘플로 제공한 기획서_예시 파일을 참고하여 진행했습니다.
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과): 기획서 내용과 A·B 초안 HTML의 작동을 직접 비교·검증했습니다. 기획서의 요구사항대로 동작하는 것을 기대했으며, 직접 테스트한 범위에서는 두 파일 모두 기능적인 문제를 발견하지 못했습니다. 영화 카드를 드래그앤드롭하는 인터페이스를 비교했을 때, A가 더 직관적이고 편리하다고 느꼈습니다.
- 선택한 파일명과 고른 이유: `영화_A_초안.html`을 선택했습니다. 두 파일 모두 직접 테스트한 범위에서는 기능적인 문제가 없었으나, A의 영화 카드 드래그앤드롭 인터페이스가 더 직관적이고 편리하여 이어서 사용할 파일로 결정했습니다.
